# config
Valores e regras que vocês editam **sem mexer em código** (YAML): premissas numéricas, limites por perfil, parâmetros das regras de validação.

Regra de ouro: quando um número passar a ser lido por código, ele vira dono aqui e `docs/` apenas o explica em prosa, sem repetir o valor.

**Não vai aqui:** lógica, fórmula, texto de relatório.

**Natureza:** humana (vocês decidem os valores). **Estado:** vazio — nada foi parametrizado ainda.
