- `regras_banca.md` — transcrição do documento do desafio. É o dono dos números e regras dados pela banca.
- `metodologia.md` — como decidimos calcular (método, não valores). Escrito por vocês.
- `decisoes/` — registro de decisões pontuais.

**Não vai aqui:** resultados de cálculo, estatísticas derivadas dos dados.

**Natureza:** humana. **Estado:** `regras_banca.md` preenchido; o resto vazio.
