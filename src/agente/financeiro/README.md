# financeiro
**Papel:** responde "dado um plano e uma carteira, o que acontece com o dinheiro ao longo do tempo".

**Entra:** perfil validado e premissas de mercado. **Sai:** projeções e indicadores de viabilidade.

**Não vai aqui:** escolher a carteira (isso é `portfolio`) nem escrever texto.

**Fronteira com `portfolio`:** aqui se mede uma carteira dada; lá se decide qual carteira ter.

**Natureza:** robótica na implementação, humana na metodologia. Nenhuma fórmula entra sem vocês definirem. **Estado:** vazio.
